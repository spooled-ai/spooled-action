# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Spooled GitHub Action, please report it privately.

**Email:** security@spooled.ai

Please include:
- A description of the vulnerability
- Steps to reproduce
- The version of the action affected
- Any potential impact

We aim to acknowledge reports within 48 hours and provide a resolution timeline within 5 business days.

## Scope

This policy covers the Spooled GitHub Action (`spooled-ai/action`) only. For vulnerabilities in the SDK (`spooled-ai` on PyPI), please email the same address.

## Out of Scope

- Vulnerabilities in third-party dependencies (please report upstream)
- Issues requiring physical access to a customer's CI runner
- Social engineering attacks

## Disclosure

Once a fix is available, we will publish a security advisory through GitHub's security advisory system and credit the reporter (unless anonymity is requested).
